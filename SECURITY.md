# Security

If you find a security problem in Spooterfy, please report it privately rather than in a public issue: use **Report a vulnerability** on this repository's [Security tab](https://github.com/ohlin/Spooterfy/security).

Things worth reporting include anything that could expose a user's Spotify sign-in tokens or Client ID, or let another app or website control Spooterfy.

This is a one-person side project, so I can't promise response times, but I'll look at every report and credit you in the fix if you'd like.

Only the latest release is supported.
